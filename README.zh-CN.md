# BladeTrace

[English](README.md)

BladeTrace 是一个可直接在浏览器运行的原型，用多段三阶贝塞尔攻击轨迹来设计和练习弹反时机。

![BladeTrace social preview](docs/social-preview.png)

## 功能

- 让敌方剑锋光标沿可配置的多段三阶贝塞尔路径移动，并支持分段缓动与时长。
- 在最后打击前开启精确弹反窗口，提供简单、标准、困难和“招式内置”四种时机设置。
- 结算完美弹反、玩家受击、敌方架势、敌方 HP 与忍殺流程。
- 提供 6 个攻击预设，包括延迟斩、连斩、跳劈、螺旋突刺轨迹与迟滞慢刀。
- 可选显示控制点、分段标签、剑锋尾迹、合成 Web Audio 反馈和敌人自动连续发招。

## 运行

不需要构建步骤或 Web 服务器。直接在当前浏览器中打开 [app/index.html](app/index.html) 即可。

本次工作已在本地 Microsoft Edge 中完成融合原型的冒烟测试；其他浏览器尚未在这里验证。

## 操作方式

| 输入 | 结果 |
| --- | --- |
| 待机时按 `Space` | 发起当前选中的攻击 |
| 攻击中按 `Space` | 尝试弹反 |
| 待机时按 `Enter` | 发起当前选中的攻击 |
| 攻击中点击画布 | 尝试弹反 |
| 架势崩溃后按 `Space` 或点击忍殺按钮 | 执行忍殺 |

连续完成 4 次完美弹反即可打满敌方架势，然后执行忍殺。玩家受击会扣除 HP 并清空敌方架势。控制区可切换招式、判定窗、轨迹辅助显示、自动循环和音效。

## 开发

在仓库根目录执行以下已验证命令：

```powershell
node --check app/game.js
node tools/verify-app.mjs
```

第二条命令会检查独立入口、必需控件、已融合的玩法钩子、无障碍标记，以及是否依赖远程运行时资源。本次融合还执行了真实浏览器冒烟测试，但仓库暂未提交浏览器测试脚手架。

## 仓库结构

```text
app/       当前可运行的融合原型
docs/      融合审计、拟议架构、路线图和社交预览素材
origin/    保留不变的 demo1/demo2 源码与设计文档，供验收比对
tools/     确定性的静态验证
```

请阅读[融合审计](docs/fusion-audit.md)了解逐项合并结果；[拟议架构](docs/architecture.md)说明验收后才进行的模块化计划；[路线图](docs/roadmap.md)说明后续阶段。

## 当前状态与限制

普通攻击的核心练习循环已经实现，但仍是轻量原型。未来架构已经完成设计，尚未实施：当前运行时代码有意保持在单个静态文件 `app/game.js` 中。

玩家架势、格挡、看破突刺、跳跃应对横扫、招式编辑器和跨浏览器兼容性测试尚未实现。原始 demo 仍保留在 `origin/`，直到融合原型通过验收；本轮没有删除旧项目。
