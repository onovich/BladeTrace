# BladeTrace

[English](README.md)

BladeTrace 是一个可直接在浏览器运行的练习场与设计工具：动作游戏开发者可观察和调节多段三阶贝塞尔攻击的节奏；不苛求高规格画面、但喜欢弹反节奏的玩家也能直接反复练习。

![BladeTrace social preview](docs/social-preview.png)

## 功能

- 让敌方剑锋光标沿可配置的多段三阶贝塞尔路径移动，并支持分段缓动与时长。
- 通过出刀阶段的刀锋接触结算：虚线圈内为成功弹反，圈外为普通拼刀，仅挡伤害、不改变架势；空心收刀不具备防御能力。
- 结算完美弹反、玩家受击、敌方架势与忍殺流程；完美弹反只累积敌方架势，不扣敌方 HP。
- 提供 13 名性格明确、多阶段的 Boss：3 名 BladeTrace 原创 Boss，以及横跨 5 款动作游戏的 10 名原创机制致敬 Boss。每名 Boss 都会随架势阈值推进阶段，并拥有不同的阶段招式池；机制致敬只取高层战斗课题，不使用原作角色或资产。
- 每位 Boss 都有原创的 Canvas 程序化视觉母题，如钟摆波纹、发条辐条、镜潮、格栅或残步，让人格可见而不复制游戏美术。
- 提供 29 个普通攻击预设，包括延迟斩、连斩、跳劈、螺旋突进轨迹、迟滞慢刀，以及 20 招专属 Boss 签名攻击。
- 对全部内置招式校验分段连续性、时长、缓动、我方刀锋参数与受击区范围，以及终点命中或落空关系；同时校验 Boss 的灵感边界、阶段阈值、阶段架势推进倍率、ID、强调色和招式池引用。
- 每个预设都提供简短练习说明：玩家可按节奏选择招式，开发者则可查看同一份底层数据。
- 可选显示控制点、分段标签、剑锋尾迹、已选武器录音及尚未替换的合成反馈和敌人自动连续发招。
- 提供仅本地生效的当前招式与 Boss 阶段画布编辑模式：可直接在运行时阶段卡中选中阶段，立即预览其招式池与强调色，或从该阶段直接开始练习；也可新增或删除阶段。高级参数中可调整阶段名称、提示、架势阈值、强调色和招式池。招式编辑仍可直接拖拽 P0–P3 控制点、红色 `R` 受击区手柄、青色攻击范围端点和虚线弹反圈；点选我方刀锋可调整出刀／收刀速度并往返预览；相邻段端点会保持连续，刷新页面即丢弃修改。

## 运行

不需要构建步骤或 Web 服务器。直接在当前浏览器中打开 [app/index.html](app/index.html) 即可。

早期融合原型曾完成 Microsoft Edge 冒烟测试；最新空间弹反与视觉改动已通过自动测试，真实浏览器视觉和手感仍待验收。

## 操作方式

| 输入 | 结果 |
| --- | --- |
| 待机时按 `Space` | 发起当前选中的攻击 |
| 攻击中按 `Space` | 尝试弹反 |
| 待机时按 `Enter` | 发起当前选中的攻击 |
| 攻击中点击画布 | 尝试弹反 |
| 架势崩溃后按 `Space` 或点击忍殺按钮 | 执行忍殺 |
| 点击“进入画布编辑” | 直接在当前招式的运行时轨迹上编辑 |

连续完成完美弹反积累架势并推进 Boss 阶段，架势满后可忍杀。我方刀锋沿固定的敌方反向路径出刀，收刀结束才能再次出刀，重复输入不刷新或排队。受击仍只在敌方招式终点结算。画布可编辑攻击范围、独立弹反圈、受击圈及出刀／收刀速度。旧毫秒窗不再生效。详见[空间弹反规则](docs/spatial-parry.md)。

## 开发

在仓库根目录执行以下已验证命令：

```powershell
node --check app/pattern-validation.js
node --check app/attack-patterns.js
node --check app/game.js
node --test tools/*.test.cjs
node tools/verify-app.mjs
```

测试命令会通过公开的招式与 Boss 阶段校验 seam 验证有效与故意无效的配置。最后一条命令会检查独立入口、必需控件、已验证的内置招式与 Boss、无障碍标记，以及是否依赖远程运行时资源。本次融合还执行了真实浏览器冒烟测试，但仓库暂未提交浏览器测试脚手架。

## 当前状态与限制

普通攻击的核心练习循环、13 名随架势推进的多阶段 Boss，以及内存内的本地招式／阶段编辑器已经实现，但仍是轻量原型。编辑器不会保存、导入、导出或写回源码；页面刷新后会恢复初始预设。当前阶段新增纯规则 seam `validateAttackPattern`、`validateBossLibrary`、`resolveBossPhase` 和 `calculatePhasePostureGain`，并扩充纯数据招式库 `app/attack-patterns.js`；浏览器整合仍位于 `app/game.js`，更大的拟议架构尚未实施。

玩家架势、格挡、看破突刺、跳跃应对横扫、可持久化/可分享的招式配置，以及本地 Edge 冒烟覆盖以外的跨浏览器兼容性测试尚未实现。敌方 HP 有意不纳入当前普通攻击循环：玩家的目标是打满敌方架势并执行忍殺。原始 demo 源码与设计文档已在融合版通过验收后移除；融合审计保留在 `docs/`，Git 历史可追溯原始材料。
