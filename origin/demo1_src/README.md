# 《斩迹 (BladeTrace)》- 只狼弹刀模拟器源码

## 1. 项目简介
《斩迹 (BladeTrace)》是一个用于模拟《只狼：影逝二度》核心“弹刀（Deflect）”机制的轻量级 HTML5 / Canvas 引擎原型。
项目通过**多段三阶贝塞尔曲线拼接**与**非线性时间缓动（Easing Functions）**，解耦招式空间轨迹与时间节奏，精准还原动作游戏中“前摇蓄力、延迟刀、瞬间爆发斩击”的变奏打击感。

## 2. 文件结构
```text
BladeTrace_SourceCode/
├── index.html       # 游戏主页面结构与 HUD
├── style.css        # 黑金/红色彩风格 CSS 样式
├── game.js          # Web Audio 音效、贝塞尔计算、粒子系统及游戏主循环
└── README.md        # 说明文档
```

## 3. 运行方式
直接在浏览器中打开 `index.html` 即可运行，无需配置任何构建环境或 Web 服务器。

## 4. 操作说明
* **发起攻击**：点击“敌方发起攻击”按钮或按下 **[Space 空格键]**。
* **进行弹反**：在敌方刀锋光标即将落至底端判定区的毫秒级窗口期内，按 **[Space 空格键]** 或点击“弹反”按钮。
* **处决忍殺**：将敌方架势条积累至 100% 后，触发“忍殺”界面，按下 **[Space 空格键]** 给予终结一击。
