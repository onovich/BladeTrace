# 我方挥刀与空间弹反

## 本轮规则

我方实心刀锋沿敌刀路径反向出刀，触碰敌刀时按两球接触点判断：虚线圈内（含边界）成功弹反并增长敌方架势，圈外普通拼刀只抵挡该次伤害。碰撞或出刀到达攻击范围后转为空心收刀，无防御能力。收刀完成前不接受新的挥刀，也不排队输入。

出刀和收刀使用独立弧长速度，不继承敌方缓动。每次动作固定路径；落空轨迹由玩家中心直线连接到敌刀终点后，再逆行原曲线。敌刀仍然只在招式终点时刻检查玩家受击圈。

## Runtime 编辑

- 青色轨迹端点：拖动调整攻击范围。
- 虚线圆周：拖动调整弹反半径；红色受击圈仍独立编辑。
- 我方刀锋小球：点选显示出刀速度、收刀速度、往返预览。
- 实心代表出刀有效，空心代表收刀冷却；按钮同步显示状态。
- 范围无法越出弹反圈时，画布显示不能产生普通拼刀的警告。

参数附属于当前招式，沿用原编辑器的内存配置方式：切换招式保留，刷新页面恢复初始数据，不新增浏览器持久化。

| 字段 | 默认值 | 单位 |
| --- | --- | --- |
| playerAttackReach | 180，实际截断至路径长度 | px |
| playerOutSpeed | 900 | px/s |
| playerReturnSpeed | 600 | px/s |
| parryRadius | max(70, 受击圈半径 + 10) | px |

双方刀锋半径为 8px。旧 parryWindowMs 被忽略，不用于配置校验、碰撞或圆径推导。预读信号依然使用敌方时间轴。

## 实现与验证

`app/player-blade.js` 提供路径弧长表、独立动作状态和扫掠球碰撞；`app/game.js` 按时间顺序处理刀锋接触与终点伤害。扫掠区间不超过 1ms，并依据速度进一步细分，限制移动量以处理高速交错。双方首个接触优先于同区间后续伤害，每次攻击仅结算一次。

成功弹反使用厚度 B；普通拼刀使用刀碰 2；敌方起势使用掠空 1。受击、阶段切换、处决音效保持原样，后续单独试听。

运行：`node --test tools/*.test.cjs`、`node tools/verify-app.mjs`。
自动化覆盖全部 Boss/阶段、圈内圈外及边界、空挥和落空、回收不防御、重复输入、低帧率一致性、画布编辑/预览和阶段推进至处决。
浏览器工具对本地 file:// 页面的访问被策略阻止，本轮未完成浏览器视觉和手感实测；上述 DOM/Canvas 测试使用模拟环境，不等同于人工试玩。
