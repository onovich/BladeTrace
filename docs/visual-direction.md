## 冷钢练刀场 · 既有实现记录

服务两类用户：研究动作机制的开发者，以及重视弹刀体验、对写实画面不苛刻的玩家。界面首先要让人看清刀锋、距离与交锋结果。

## 设计决定

- 深蓝钢 `#101b26`：页面背景；钢蓝 `#182936`：HUD 与编辑器。
- 雾白 `#edf1ec`：正文；蓝灰 `#a6b9c3`：辅助信息。
- 青玉 `#79e8dc`：我方刀锋与攻击范围；琥珀 `#edb66b`：敌方架势与交锋余光。
- 标题采用本机宋体 / 宋体风格衬线字，正文使用微软雅黑 / 苹方，参数保留等宽字。无需外部字体服务。
- 桌面为「战斗画布 + 右侧练习控制」，小屏回到上下布局；避免把调参工具挤进战斗画面。
- 标志性元素仍是可编辑的刀锋轨迹及交锋粒子，不新增装饰性动效。粒子数量、运动和颜色均未改动。
- 范围、半径、出刀/收刀状态仍通过形状和文案表达，不仅依赖颜色。

主题集中在 app/theme.css；保留原布局基础样式，游戏几何和判定不变。Canvas 只调整背景，不改变碰撞或采样。
