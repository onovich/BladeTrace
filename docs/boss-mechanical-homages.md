# Boss 机制致敬目录

## 边界

BladeTrace 当前有 13 位可练习 Boss：3 位 BladeTrace 原创 Boss，以及 10 位来自 5 个动作游戏的**机制致敬** Boss。这里的“致敬”只取公开可观察的战斗课题——节拍、压迫曲线、前摇承诺、阶段转折与学习曲线——并重新设计名字、视觉语言、轨迹、招式文本和人格。

仓库不包含、也不复用参考作品的角色名、模型、图像、音乐、台词、剧情、地图或关卡表达。因此它们是原创训练配置，不是原作 Boss 的逐字逐帧复刻。

## 当前 Boss 优化

所有 Boss 保持三个架势阶段（0%、50%、75%），但不再让后两阶段只出现一次就结束：

- 阶段 I 的单次完美弹反按招式基础架势收益推进（常见为 `+25%`），两次成功会到 50%。
- 阶段 II、III 使用 `×0.5` 阶段推进倍率；常见为每次 `+12.5%`，因此各自都有两次成功读招的机会。
- 进入新阶段时，战斗短暂停拍、显示阶段标题并播放独立提示音；之后才重新安排攻击。
- 每套内置招式都定义了 380–450ms 左右的命名“预读信号”。它在正式弹反窗口之前出现，帮助人类玩家从前摇做决定，而不是把 150ms 或 220ms 当作纯视觉反射题。
- 每位 Boss 都有一组原创的 Canvas 程序化视觉母题（如钟摆波纹、镜潮、发条、格栅和残步）；它随阶段强调色变化，补足人格辨识，但不使用参考作品的任何资产。

## 阶段练习与所见即所得编辑

进入画布编辑后，直接点击阶段卡即可看到该阶段的强调色、招式池和轨迹。点击“练习此阶段”会从该阶段的架势阈值开始实战；受击或重置会回到该阶段，便于反复学习阶段 II、III，而不必每次从 0% 重新推进。阶段名称、描述、阈值、颜色和招式池仍可在按需展开的高级参数中编辑；路径、受击区和弹反窗继续在画布上直接调整。

试玩口径和三类人类化模拟参数见[人类动作玩家试玩协议](human-playtest-protocol.md)。
