# 融合审计：demo1 → BladeTrace 融合版

## 结论

`app/` 是已验收的唯一融合版：它以 demo1 的黑金、红色强调、纵向敌我布局和 Space 上下文操作为视觉及交互底板，同时吸收 demo2 已实现、而 demo1 缺少的可观察性、战斗结算和练习选项。原始 demo 源码与设计文档已在验收后移除；本审计与 Git 历史保留了决策依据和原始材料。

## 产品意图的共同部分

两份设计文档都描述同一个轻量浏览器原型：把敌方攻击拆成首尾连续的多段三阶贝塞尔曲线，再对每段分别应用缓动和时长，以呈现蓄力、迟滞、爆发等不同节奏；玩家在攻击终点前的毫秒窗口内按键弹反，利用架势崩溃触发忍殺。

它不是《只狼》的复刻或完整战斗游戏，而是一个可视化、可调试的“招式轨迹 + 弹反节奏”实验场。

## 有意识地没有照搬的内容

- demo2 的宽屏、蓝灰卡片布局没有引入，以遵守“以 demo1 视觉和交互为底板”的要求。
- 两份文档都提到玩家架势、危字攻击、看破与跳跃，但现有两份源码均未真正实现完整流程；它们被标记为后续路线，而非在 README 中表述为已有能力。
- demo1 文档写到“玩家架势清空/受损”，demo2 源码实际实现的是“玩家受击时敌方架势清空”。融合版采用后者，以保持已实现的练习循环；玩家架势需要单独的规则设计后再加入。

## 验收建议

1. 直接打开 [`app/index.html`](../app/index.html)，依次体验 6 个招式。
2. 在简单、修罗、苦难及“招式内置判定窗”之间切换，确认时机差异可感知。
3. 用按钮、Space 和画布点击各完成一次弹反；连续完成 4 次，确认忍殺与重置流程。
4. 开关“显示轨迹与控制点”“敌人自动连续发招”“音效”，确认练习配置的行为符合预期。

验收已通过：`app/` 已成为唯一项目目录；`origin/demo1_src`、`origin/demo2_src` 及其原始设计文档已移除。
