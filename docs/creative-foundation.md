# 创作基线：白垩剧场与浮空塔奥术对决

日期：2026-10-03。本文记录题材与视觉决定，区分用户确认、设计解释和开放问题；不表示对应内容已经实现。

## 已确认

- 正式美术方向选用「白垩剧场」，母稿为「白室决斗」。原图见 [白垩剧场](art-directions/2026-10-03-white-2d/01-white-gouache.png)；旧探索保留，但不再作为并行的正式方向。
- 题材为带科幻气质的现代魔法对决。沙丘、星战是气质参考，不是共用世界观或可复用角色、术语、剧情与资产。
- 玩家与敌人的交锋是学院派奥术，不是实体刀剑互砍。概念图中的持刀人物是待替换的题材占位，不是已确定的角色设计。
- 世界舞台为浮空塔。主角闯入／攀登浮空塔，挑战皇帝。
- 皇帝基础设定已确认「最后一个救世主」：为终结真实的奥术灾难与救世主依赖，他背弃自己建立的制衡，杀师夺书、兼修全部奥术；主角登塔复仇并执行制裁。主角具体人格与经历、塔中流程仍未定。
- 本轮不改成 3D，不实施战斗改造；当前游戏仍是刀剑表现的可运行原型。

## 产品理解

拟议定位：一款以读招、空间迎击与精准反制为核心的风格化奥术决斗游戏。玩家通过与不同施法者对决，逐渐掌握对手的术式语言，向皇帝所在的位置推进。

“登塔挑战皇帝”已有复仇与制裁的因果。皇帝理想、才能与罪同时真实；主角反对替所有人选择牺牲，也没有保证成功的替代方案。皇帝死亡是保留的悲剧结局方向，不是已经锁定的执行细节。完整状态见 [皇帝设定基线](story/emperor-foundation.md)，原始确认稿与来源也已归档。

原先面向动作游戏玩家与动作机制开发者的双重价值可以保留：前台提供完整的决斗体验；本地按需开启的可视化编辑与观察工具继续服务研究、设计和练习。是否正式从“练习场”升级为含完整流程的游戏，仍需后续界定规模。

## 气质解释与建议（非既定世界观）

### 现代，不等于赛博朋克

建议采用简洁服饰、抽象建筑、克制的器具与清晰信息设计；避免霓虹铺屏、繁密机械装甲和传统奇幻装饰堆叠。科技感来自精确、秩序与系统性，不需要此时解释魔法究竟是不是科技。

### 学院派，不等于校园故事

奥术可被学习、拆解、演算与训练，具有基础法则、施法程序和流派差异。施法者的个性体现在对同一套规则的不同使用方式，而不是只靠元素颜色换皮。现已确认学院曾分立知识、主角由多位大师共同培养；学院具体组织与训练生活仍开放，不转为校园故事。

### 科幻史诗感，不等于照搬参考作品

建议提取宏大而寂静的尺度、仪式化交锋、权力秩序与少量异质技术感。不要预设沙漠宗教、预言血统、光剑、原力或特定帝国组织。浮空塔自身应形成原创的视觉与制度身份。

## 战斗机制的题材转译建议

下列名称仅作创作工作用语，尚未决定正式 UI 名称，更未重命名代码。

| 现有机制 | 奥术解释建议 | 规则边界 |
| --- | --- | --- |
| 敌方多段攻击轨迹 | 正在运行的术式路径 | 仍需可读、可学习，不被装饰遮住 |
| 敌方刀锋小球 | 术式的有效作用点／术核 | 清楚表达何处会发生碰撞，而不是整条尾迹都能伤人 |
| 玩家沿反向轨迹出刀 | 沿对方术路送出反制脉冲 | 当前是自动追随固定路径，不能宣传成玩家自由绘制法术 |
| 攻击范围 | 本次反制能抵达的术路长度 | 不等于玩家圆形受击范围 |
| 圈内成功弹反 | 精准反制，扰乱对手的施法稳定性 | 保留空间碰撞和精确迎击收益 |
| 圈外普通拼刀 | 普通消解／抵消本次攻击 | 挡伤害，但不积累敌方崩溃值 |
| 敌方架势累积 | 施法失稳或术式破绽累积 | 当前条越满越接近崩溃；若称“稳定度”，必须解决增长方向相反的问题 |
| 收刀后摇 | 反制回收／回路复位 | 空心作用点不防御，不暗示持续护盾 |
| 受击圈 | 本体受击边界 | 与反制圈保持独立 |
| Boss 阶段 | 对手切换术式结构、策略或释放限制 | 不新增规则也能先利用已有阶段与招式池 |
| 忍杀 | 破局后的终结术式 | 是否致死尚未确定，暂不把“忍杀”作为正式题材用语 |

核心体验建议表述为：读懂术式 → 主动迎击 → 精准干涉 → 累积破绽 → 打开终结机会。不是站桩互丢魔法弹，也不需要本轮添加蓝条、元素克制、技能栏或自由施法系统。

题材疑问需要以后验证：为什么反制顺着敌方路径运行？候选解释是“术式释放后暴露了可被解析和干涉的路径”。这只是适配现有机制的解释，不是现在定死的宇宙法则。

## 白垩剧场的落地方向

- 保留白垩质感、黑白大色面、克制红色、巨大建筑平面与安静留白。
- 采用 2D 绘制的背景与角色。画面允许透视和建筑空间感，不意味着必须使用 3D 引擎。
- 原稿的刀与挥刀姿势应重新设计为施法动作；不能只给剑加光效便声称完成奥术题材转型。徒手、法器或其他媒介尚未确定。
- 术式的装饰和碰撞反馈分层：装饰可以复杂，实际作用点、反制圈、受击圈和有效范围必须简明。
- 保留交锋粒子的力度和节奏，但未来将物理金属碎屑转译为术式裂解、微光或几何碎片，不能遮挡下一次读招。
- 原选金属接触声音可作为节奏与清脆度参考；是否保留为奥术音色的一层需另做试听，不将它们自动视为最终声音。
- 浮空感可由远景、天光、云层与边界体现，不要求在战斗有效区域堆入运动背景或空间障碍。

## 对手与登塔结构建议

Boss 差异优先来自施法习惯：严谨的分段构式、诱导性的延迟释放、持续压迫的连式、回旋与路径折返等。先让玩法中的性格成立，再决定其职业、职位和剧情立场。

现有 Boss 和机制致敬配置可继续充当节奏实验素材，不自动成为新世界观的正式人物名单。塔的层级适合作为对决推进框架，但不据此预设每层一个 Boss、随机爬塔、Roguelike、探索关卡或永久升级系统。

## 刻意留白

- 主角的具体身世、人格、训练生活与组织关系；多师培养和制裁定位已确认。
- 当前出发的具体时间压力、接近皇帝的机会、中段主动决定；复仇、违约制裁与阻止强制牺牲的因果已确认。
- 皇帝与浮空塔的具体关系、计划实施步骤、最终是否死亡；皇帝动机与悲剧缺陷已确认。
- 塔为何浮空、有何用途、是否唯一、进入和登塔规则是什么？
- 对决是否允许致死，胜利是否意味着杀死对手？
- 是纯 Boss 连战、线性叙事关卡，还是包含探索与其他玩法？

这些问题尚无答案，不用占位设定冒充已确认事实。

## 建议的下一步顺序

1. 先做一张真正的“奥术版白垩剧场”：替换持刀角色与动作，展示普通抵消、精准反制、失稳终结的视觉语义。
2. 用一个原创奥术对手做题材验证，沿用已稳定的底层规则，不同时扩展战斗系统。
3. 叙事继续以已确认皇帝为基础设计主角、人物关系与塔的流程规模；美术验证不替代叙事确认，也不要求重开皇帝选案。
