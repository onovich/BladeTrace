# 主角设定基线：从敕杀使命中走出去的人

更新：2026-10-03。确认等级：用户认可“非常有意思，大部分都应该保留，少部分需要日后打磨磋商”。保留核心方向，不将每个示例锁为正史。

## 人物与故事方向

主角不是特殊血统或天选之子，而是多位最高奥术大师共同培养、专门研究“强者如何失败”的战斗者。他学习术式成立、不可撤回的时刻、薄弱位置与高手隐藏缺口的方法；多师训练形成跨体系识别、拆解与迎击能力，不是一敌一书一技能的收集。

他不愿把一生耗在等待皇帝犯错上，年轻时主动离开敕杀体系，去现实中的危险现场，把原本用来弑君的本领用于救援与战斗。这不是皇帝或老师预知灾难后的安排。正因为他早已自行离开，杀师时不在师门而幸存；具体地点、时间与职业仍待设计。他可能留下“如果当初没走”的伤口，但不以整日阴郁自责为主。他确实恨皇帝、想为老师复仇，不必通过放弃复仇或宽恕来证明成长。

人格方向是直接、行动迅速、嘴不饶人、有坏脾气、缺乏对神圣仪式的敬畏，偶尔有幽默。他受过高等级学院教育，知道复杂理论终须落实到谁行动、谁付代价；不是无知莽夫，也不是永远正确的温和圣人。

主角与皇帝同样强大、自信、果断、厌恶无所作为，敢首先承担风险。区别是皇帝把责任转成替他人决定牺牲的权力；主角认为责任首先规定自己应承担什么，不因此获得分配别人牺牲的资格。但“那我来”也成为主角的自负：他总把困难扛走，使别人无法真正分担，可能重演所有人依赖唯一强者的局面。皇帝能看穿他，是有真实理解的镜像对手，不只是供他训诫的暴君。

老师们真心关心主角，却对是否应把孩子塑成制裁工具、是否终身待命、是否必须走出去生活存在分歧。保留关系不齐一的方向；具体人数与每人的配置尚未定。主角见过真心限制自己的年轻皇帝，两人可以有真实欣赏与训练往来；相处频率、亲密程度、具体场景仍待打磨。

“唯一不必向皇帝下跪的人”是重点保留、待打磨的辨识度设计：不是地位特权，而是教育他不将皇位神圣化。幼年被老师拎起、皇帝阻止行礼等属于候选场景，不是已锁定演出。同样，“得知杀师后先救完眼前的人”是行为表达方向，不是必须放在游戏开场的既定事件。

人物弧线：不愿为弑君而活，主动离开 → 因杀师而想复仇 → 登塔时重新判断计划与代价 → 即使没有旧敕令，仍自行选择阻止皇帝。自由不是一定反着使命做，而是相同的行动终于出自自己的判断。最终杀死或彻底制止皇帝的具体执行仍未定，也没有保证成功的第三方案。

战后方向是承担自己行动的后果，拒绝把最强的能力换成永久统治资格；不是简单拒绝王冠便甩手离开。战斗表达上皇帝组合、补足，主角观察、切入、拆解。奥术指针／演算杆仅为候选媒介；白色迎击轨迹也不是已验收美术。不能因人物设定获认可就宣称相应剧情、角色或动作已实现。

## 尚待打磨

- 姓名、准确年龄、身世细节、离师年份、前线组织与具体职业。
- 老师人数、各自性格与彼此关系；主角与年轻皇帝相处的尺度。
- 免跪规矩的具体呈现；所有台词与回忆场景。
- 杀师当日主角的具体行动、登塔中不可撤回的决定、战后实际承担的责任。
- 施法媒介、造型、动作；皇帝生死和结局执行。

## 最新叙事进度（用户构想，尚非完整方案）

用户随后提出：游戏开始时主角已经在塔上；每场战斗解锁部分剧情；每隔几场战斗休息，通过梦境倒叙并亲历过去的战斗补足前史。倾向碎片化、卡片化、结构化文本，不喜欢大量对白灌输；当前难点是如何向玩家交代皇帝故事。
