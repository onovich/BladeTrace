# 皇帝设定基线：最后一个救世主

更新：2026-10-03。状态：用户已整体认可；这是人物与故事因果基线，不是已完成的关卡剧本或游戏实现。“最后一个救世主”是题眼，不是游戏正式更名。

## 一句话

一个毕生想让人类不再需要皇帝的人，最终把自己变成了人类历史上最不可替代的皇帝。

## 已纳入项目的核心

皇帝有真实才能、野心、极端自负和崇高理想，杀伐果断，坚信自己能引领人类走上解救之道，为此愿意牺牲一切。他是悲剧人物，不是借救世口号掩饰私欲的普通暴君。

他成长于依赖少数大师、英雄与君主的文明，真诚反对普通人的命运由某个伟大人物是否愿意、是否能够出手决定。年轻时统一国家、打破奥术门阀，也主动限制自己：皇帝不得兼修全部奥术，并认可多位大师共同培养能够制裁违约皇帝的战斗者。主角就是这项真实制衡，不是皇帝安排的求死工具。

战争与救灾中的一次次成功不断奖励他的自负。他逐渐从“所有强者都应受限制”，走到“限制不应阻止真正正确的人”。他仍以为自己忠于原有理想，却不断把自己变成原则的例外。

文明的浮空建筑、能源、医疗、运输与战争依赖奥术。不同体系来自同一个正在失稳的根源，局部灾难已经发生，全面灾变是有根据的重大风险，不是皇帝编造的借口，也不是全知预言。

皇帝要彻底切断人类与根源的联系，终结奥术时代，使普通人的世界不再依赖超人和救世主。但实施计划必须统一掌握全部奥术；这样的人又几乎无法被其他奥术师制止。禁约保护的正是皇帝之外仍然存在的反抗能力。

大师们承认威胁，也承认计划可能有效；拒绝的原因是骤然失去奥术将使城市、医疗与保护体系崩溃，造成大量死亡与漫长动荡。他们主张延缓、研究、渐进转型，却无法承诺另一条道路的完成时间。皇帝不能接受“不知道”，遂冷静地杀死反对者、夺走全部典籍，违背禁约。主角的全部师父被杀，复仇与制裁因此重合。

这些大师与皇帝有真实旧交，包括师承、共同建国和支持登位；不能把他们全部写成无能、贪婪或该死的人来替皇帝消罪。具体执行杀戮者与事件时序仍未定。

主角是年轻皇帝留给未来自己的一票否决。皇帝承认这项制衡曾被自己认可，却认为年轻的自己没有承担今天的责任。他会全力杀死主角、完成计划，不是等待刺杀或把失败当作计划的一环。

双方冲突不止于自由对独裁：皇帝要用巨大的牺牲换取他确信的安全未来；主角拒绝他替所有人选择牺牲，却没有一条保证成功的替代道路。皇帝的才能、理想与罪都必须真实，不能靠揭露灾难虚构或计划毫无效果来消解冲突。

## 七重矛盾，同一个因果

| 理想 | 行动造成的反面 |
| --- | --- |
| 不再依赖救世主 | 成为最大的救世主 |
| 反对皇权神圣 | 建立最绝对的皇权 |
| 人类自己决定未来 | 替所有人作出最大决定 |
| 结束不断的牺牲 | 发动巨大牺牲 |
| 创造自身的制衡 | 杀死维持制衡的人 |
| 终结奥术 | 先掌握全部奥术 |
| 无人不可替代 | 让计划只剩自己能完成 |

他的悲剧缺陷：确实比绝大多数人强，因而相信强到一定程度便获得了替所有人决定的权利。已经付出的代价又使他越来越无法允许自己怀疑。

## 已认可的方向，不等于锁定执行细节

- 皇帝战斗应表现不断组合术式、弥补弱点的性格，不是火冰雷轮流登场。主角依靠观察、判断、主动迎击，而非万能答案。具体招式、适应机制与阶段未实现，不授权不可读的即时反制或机器读输入。
- 保留悲剧结局方向：主角击败乃至杀死皇帝，阻止眼前的强制牺牲，长期灾难仍待解决。胜利恢复选择而非得到完美答案。皇帝不必忏悔，也不必被证明计划无效。
- 皇帝是否死亡、最后对白、计划被打断到哪一步仍待确认。原件中全部台词都是候选；不能把“别浪费它”等直接视为定稿台词。
- “唯一解”“确定未来”是皇帝的信念，不是作者给他的全知正确性担保。

## 待继续设计

主角具体人格、身世、生活与训练经历、同皇帝的旧关系、杀师时去向；皇帝姓名、年龄、具体功绩；敕杀启动、杀师、夺书、学习与计划启动的完整时间线；灾难征兆及方案代价的具体人群；塔的功能与计划的联系；少量阵营和 NPC 的关系；主角在中段主动改变局面的事件；流程规模与结局细节。

还需解释：为什么必须由一人统一体系、为什么合作或渐进过渡不能及时达到同样目的、皇帝为何能先发制人、主角如何真正有机会战胜兼修者。以上是基线的待补因果，不用新术语或旧弃案代填。

仍要避免“一敌一典籍一能力”的固定复仇名单。确定皇帝不等于主角、塔中段或完整故事已经完成。
