# 人类动作玩家试玩报告

**日期：** 2026-09-04  
**范围：** 三名模拟人类动作玩家各自试玩一个多阶段 Boss；不把自动化点击速度当作人的反应能力。具体基准见[试玩协议](human-playtest-protocol.md)。

## 试玩者与结论

| 试玩人格 | 关注 Boss | 人类模型 | 结论 |
| --- | --- | --- | --- |
| 初次接触的普通动作玩家 | 灰烬监军·烬卫 | 290ms 中位、约 ±70ms 波动；需 8–12 次接触 | 长前摇适合学习，但 150ms 不适合作为首次默认；阶段 II、III 太短，难以建立人格记忆。 |
| 常见的熟练动作玩家 | 雾鸦舞姬·折羽 | 250ms 中位、约 ±45ms 波动；2–4 次重复后建立节拍 | 假动作、阶段文案和换池形成一致人格；220ms 可作为学习档，150ms 必须预读。 |
| 经常玩弹反类动作游戏、但非职业级 | 铁钟守卫·鸣壁 | 225ms 中位、约 ±35ms 波动；1–2 轮后可预判 | 重型前摇可学，Boss 阶段卡和实战池同步明确；自动循环更像压力测试而非首次教学。 |

## 实际观察

- 三名 Boss 都能显示阶段 I、II、III 及其人格提示；编辑模式中的阶段卡可直接预览对应招式池与强调色。
- 架势达到 50% 和 75% 时，实战 HUD、阶段标题、状态提示和当前招式下拉池同步切换；玩家受击后架势清零并回到阶段 I。
- 雾鸦在 220ms 档的两次推进实际到达阶段 II、III；150ms 的自动化操作曾受击。这只验证了界面行为，**不是**人类成功率数据。
- 未发现阻断试玩的 P0 问题，也没有观察到控制台错误或警告。

## 共同反馈与处置

### 已采纳

1. **首次默认档改为“练习 · 220ms”。** 三位试玩者均认为 150ms 小于其人类反应基线，只有在已读懂前摇时才合理；150ms 继续保留为“修罗”挑战。
2. **保留 150ms 的定位说明。** README 与试玩协议明确它依赖攻击前摇的预读，而不是判定窗出现后的纯反应。

### 下一轮平衡工作

1. **阶段驻留时间。** 当前每次完美弹反增加 25 架势，50%/75% 切换、100% 忍殺；完美循环中，阶段 I 有两次成功攻击，阶段 II 与 III 各只有一次。这不足以让普通玩家习得后两阶段的节奏。
2. **预读信号。** 在终结落点前约 350–450ms 增加稳定且可区分的视觉或音效承诺信号；目标是让失败可归因于读招或节奏，而不是随机。
3. **阶段转场节拍。** 阶段切换后增加短暂断点、标题或专属音效，再进入新招式池，避免玩家误解为随机变速。
4. **练习循环。** 设计“重复当前招 / 阶段混合”模式与受击后的复盘空档；阶段 II、III 也应能被直接练习，而不强迫每次从 0% 架势重打。

这些项目尚未实施，避免在没有确认战斗总时长与架势经济目标的情况下，擅自改掉现有“四次完美弹反 → 忍殺”的练习循环。
